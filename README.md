# full_stack_code_workbench_live_previewer
The Full-Stack Code Workbench &amp; Live Previewer is a single-page web sandbox for writing and running full-stack projects directly in the browser. It features tabbed editors for HTML, CSS, JS, Node.js, and SQL, an in-browser SQLite engine powered by sql.js, an isolated live preview iframe, console output, and single-file HTML export.
